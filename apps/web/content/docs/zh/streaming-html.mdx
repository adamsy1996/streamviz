## HTML 就是可视化产物协议

模型生成自包含的 `widget_code`，其中可以包含 HTML、SVG、inline CSS 和可选的 inline JavaScript。外层 tool call 只是 transport；真正的 artifact 是 HTML。

```html
<section class="analysis">
  <style>/* artifact-local styles */</style>
  <svg role="img" aria-label="趋势">…</svg>
  <button id="follow-up">解释变化</button>
  <script>/* 仅在 final 后启用 */</script>
</section>
```

## 部分恢复

`extractPartialJsonString(raw, 'widget_code')` 可以解码当前 JSON string，即使外层对象与字符串本身都尚未闭合。

## 渲染释放

仅收到一个起始标签时，StreamViz 不会展示空 iframe。只有当文档已经包含有意义文本，或 `svg`、`canvas`、`img`、`table`、`button` 等视觉元素时，才开始被动渲染。

## 流式安全

当 `final` 为 false：

- 主动脚本会被移除。
- 事件属性不能执行。
- 不安全外部 URL 会被移除或重写。
- iframe 始终处于 sandbox 中。
- 新的被动 HTML 可以持续原位更新。

当 `final` 变成 true，StreamViz 只构建一次最终 document，并启用安全交互桥。

## 模型编写规则

1. 先输出可见结构，再输出可选脚本。
2. 使用 inline style，不加载外部资源。
3. 使用稳健的 grid 与 flex layout。
4. 消费 `--sem-text-primary` 等语义变量。
5. 通过全局 `sendPrompt()` 发起宿主追问。
