StreamViz 提供 protocol helpers，避免模型 prompt、工具名称、最终 metadata 和 renderer 独立漂移。

## 工具调用顺序

1. 模型以最接近的 artifact type 调用 `visualize_read_me`。
2. 宿主返回 package 中的 authoring rules。
3. 模型调用 `visualize_show_widget`，传入 loading messages、HTML 与 title。
4. 宿主把工具参数流式发送到 UI。
5. UI 归一化并渲染持续增长的 `widget_code`。

支持 `diagram`、`chart`、`interactive`、`mockup` 与 `art`。

## 构建 system prompt

```ts
import { buildVisualizeSystemPrompt } from 'streamviz/protocol'

const systemPrompt = [
  baseSystemPrompt,
  buildVisualizeSystemPrompt(),
].join('\n\n')
```

## 持久化最终 metadata

```ts
import { buildVisualizeWidgetMetadata } from 'streamviz/protocol'

const metadata = buildVisualizeWidgetMetadata({
  title,
  widget_code,
  loading_messages,
})
```

即使不同 provider 的 live transport 不同，最终客户端都能消费同一份稳定结构。
