---
title: 宿主 API
description: 把 artifact 动作连接到应用图标、剪贴板、通知与对话流程。
---

iframe 负责视觉执行，宿主负责应用能力。StreamViz 通过窄接口连接两侧。

## Agent 追问

artifact 脚本可以调用：

```js
sendPrompt('解释最大的营收风险')
```

React 宿主负责处理：

```tsx
<StreamVisualization
  {...payload}
  onSendPrompt={(prompt) => conversation.submit(prompt)}
/>
```

## 通知与剪贴板

```tsx
<StreamVisualization
  {...payload}
  notify={(message, variant) => showToast({ message, variant })}
  writeImageToClipboard={(dataUrl) => desktopBridge.writeImage(dataUrl)}
/>
```

StreamViz 只请求 `success` 或 `error`；展示位置、时长和可访问性由宿主决定。

## 宿主图标

```tsx
<StreamVisualization
  {...payload}
  renderIcon={(name, { className }) => (
    <Icon name={name} className={className} />
  )}
/>
```

支持 `check`、`copy`、`download` 和 `code-xml`。
