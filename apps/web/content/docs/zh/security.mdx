StreamViz 把模型生成的 HTML 视为不可信输入。安全采用多层设计，避免任何单一 parser 或浏览器行为成为唯一边界。

## Sandboxed iframe

```html
sandbox="allow-scripts allow-forms"
```

artifact document 与宿主 origin 隔离，不能读取宿主 storage、访问宿主 DOM 或导航顶层应用。

## Content Security Policy

每份 `srcDoc` 都带有严格 CSP，阻止网络依赖，并把执行能力限制在 StreamViz 明确放入 document 的内容内。

## 流式净化

运行中的 artifact 始终是被动内容。StreamViz 会在渲染 partial HTML 前移除主动内容，并在宿主确认 final 后才允许脚本执行。

## 宿主责任

- 不要给 sandbox 增加 `allow-same-origin`。
- 不要把宿主 secrets 作为 CSS 变量或 HTML 转发。
- 把 `onSendPrompt` 内容继续作为不可信输入处理。
- 导出、复制与持久化前执行应用自身的权限检查。

> 主题只改变视觉语义，不能替换 sandbox、sanitization、CSP、measurement 或 final-state 行为。
