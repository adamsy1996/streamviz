每个 artifact 都会获得一份完整内置样式。宿主不需要把 Tailwind、Radix 或应用 CSS 注入 iframe。

## 跟随宿主模式

```tsx
<StreamVisualization
  {...payload}
  theme={{ mode: 'system' }}
/>
```

`mode` 支持 `light`、`dark` 和 `system`。

## 覆盖语义 token

```tsx
<StreamVisualization
  {...payload}
  theme={{
    mode: 'dark',
    tokens: {
      accent: '#2563eb',
      backgroundMuted: '#eef1f5',
      statusSuccess: '#0f9f77',
      radiusLarge: '12px',
      chartSeries: ['#2563eb', '#0ea5a4', '#6d5bd0'],
    },
  }}
/>
```

token 覆盖背景、文本、边框、accent、status、radius、font 与最多八组 chart series。

## 使用内置 Artifact utilities

iframe runtime 为生成式 HTML 提供了一组小型、带命名空间的编写原语：

```html
<section class="sv-grid">
  <article class="sv-card sv-card-muted">
    <p class="sv-label">营收</p>
    <p class="sv-value">¥842 万</p>
    <span class="sv-badge sv-badge-success">增长 12.4%</span>
  </article>
</section>
```

这些 `sv-*` 原语是普通 CSS，不需要 Tailwind runtime，并且会自动跟随当前主题。

## Artifact CSS

```css
.panel {
  color: var(--sem-text-primary);
  background: var(--sem-bg-card);
  border: 1px solid var(--sem-border-subtle);
  border-radius: var(--sv-radius-lg);
}
```

公开集成优先使用 typed `theme.tokens`；`cssVarNames` 只作为连接现有设计系统的高级适配层。
