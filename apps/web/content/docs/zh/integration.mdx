## 在边界层归一化

不同 Agent framework 保存 tool call 的结构不同。通过一次 normalization，把 transport 差异隔离在可视化组件之外：

```tsx
import {
  StreamVisualization,
  extractVisualizeWidgetPayload,
} from 'streamviz'
import 'streamviz/styles.css'

export function ToolArtifact({ toolCall }: { toolCall: unknown }) {
  const payload = extractVisualizeWidgetPayload(
    toolCall as Record<string, unknown>,
  )
  return <StreamVisualization {...payload} />
}
```

helper 能识别 `arguments`、`input`、`state.input`、`metadata`、`state.metadata`、`tool_raw_input`、`raw_input` 和 `state.raw`。

## 运行状态

工具运行时，宿主通常只有未闭合的序列化参数：

```ts
const toolCall = {
  tool_status: 'running',
  raw: '{"title":"营收驾驶舱","widget_code":"<section',
}
```

StreamViz 不需要等待外层 JSON 完成，就能恢复其中的 HTML 字符串。

## 接入宿主适配器

```tsx
<StreamVisualization
  {...payload}
  theme={{ mode: appTheme }}
  onSendPrompt={(prompt) => submitFollowUp(prompt)}
  notify={(message, variant) => showToast({ message, variant })}
  writeImageToClipboard={writeImageToClipboard}
/>
```

宿主负责 toast、clipboard、图标、主题与对话行为；StreamViz 负责隔离渲染生命周期。
