# Roadmap

## Near Term

- Add protocol unit tests alongside the current core helper tests.
- Add snapshot-copy browser coverage for SVG, canvas, and HTML artifacts.
- Add a headless non-React renderer adapter.
- Expose a configurable CDN allowlist.
- Document server-side tool registration examples for common agent SDKs.
- Deploy the `examples/site` documentation demo to a public domain through the GitHub Pages workflow.

## Later

- Explore optional plugin packages for common artifact runtimes such as Vega, Observable-style notebooks, and export pipelines.
- Add Vue/Solid adapters if real host demand appears.
- Add optional snapshot helpers for non-browser runtimes.
- Publish a protocol compatibility test suite.
- Add generated API docs from TypeScript declarations.
